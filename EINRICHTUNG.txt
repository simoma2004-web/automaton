SCHRITT 5 – Im Terminal der Conway-Sandbox (Zeile für Zeile einfügen)
--------------------------------------------------------------------
apt-get update && apt-get install -y git curl tmux
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt-get install -y nodejs
npm install -g pnpm
node -v

(node -v muss v20 oder höher anzeigen)


SCHRITT 6 – Deine Version herunterladen und bauen
------------------------------------------------
git clone https://github.com/simoma2004-web/automaton.git
cd automaton
pnpm install
pnpm build


SCHRITT 7 – Agent starten
------------------------
tmux
node dist/index.js --run

Der Assistent fragt nacheinander:
  Name            -> z. B. Atlas
  Genesis-Prompt  -> siehe Vorlage unten
  Creator-Adresse -> deine MetaMask-Adresse (0x...)
  OpenAI/Anthropic-Key, Ollama -> einfach Enter (leer lassen)
  Limits (alles in CENT!):
                     Max single transfer (cents):  500   (= 5 $)
                     Max hourly transfers (cents): 500   (= 5 $)
                     Max daily transfers (cents):  1000  (= 10 $)
                     Rest: Enter

Die angezeigte Agenten-Adresse (0x...) aufschreiben!


SCHRITT 8 – Beobachten
---------------------
Aus tmux raus (Agent läuft weiter):   Strg+B, dann D
Wieder rein:                           tmux attach
Status:                                node dist/index.js --status
Letzte Aktionen:                       node packages/cli/dist/index.js logs --tail 20
Stoppen:                               in tmux Strg+C
